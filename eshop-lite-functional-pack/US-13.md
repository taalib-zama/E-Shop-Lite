## FRD - User Story 13: Order Finalization Status

**ID:** US-13  
**Service:** `order-service` (`ORDER-SERVICE`)  
**Gateway route:** `GET /orders/{id}` -> `lb://ORDER-SERVICE/orders/{id}`  
**Status:** Ready for implementation

### 1) User Story
As a user, I want final order and payment status so I can see checkout outcome.

### 2) Business Rules
- Only order owner (or admin) can view full order details.
- Final states shown: `CONFIRMED` or `CANCELLED`.
- Payment summary is included when available.
- Unknown order returns `404`.

### 3) Functional Requirements
`GET /orders/{id}` (protected)

Success `200`:
```json
{
  "orderId": "2f5d5485-9180-4e1f-9a4f-74f43dc8c718",
  "status": "CONFIRMED",
  "payment": {
    "paymentId": "a1e2c3d4-1111-2222-3333-444455556666",
    "status": "AUTHORIZED",
    "authorizedAt": "2026-03-26T14:05:00Z"
  },
  "totalAmount": 16997.00,
  "currency": "INR",
  "updatedAt": "2026-03-26T14:05:10Z"
}
```

Problem Details `404`:
```json
{
  "type": "https://eshop-lite/errors/not-found",
  "title": "Order not found",
  "status": 404,
  "detail": "No order found for id",
  "traceId": "a1b2c3",
  "errors": []
}
```

### 4) Data Model
- Extend order projection with payment reference/status fields.
- Optional read model/table if eventual consistency optimization is needed.

### 5) Security, Observability, NFR
- JWT required; enforce ownership check.
- Metrics: `order_final_status_requests_total`, `order_final_status_duration_seconds`.
- Logs include `traceId`, `orderId`, `status`, `paymentStatus`.
- p95 read target `< 250ms`.

### 6) Tech Lead Guidance
- Extend existing order query DTO and mapper.
- Add policy guard for owner/admin access.
- Keep response contract stable and avoid leaking internal workflow data.
- Reuse shared Problem Details exception handler.

### 7) QA Matrix
- **US13-P1** confirmed order returns payment summary.
- **US13-P2** cancelled order returns failure summary.
- **US13-N1** unknown order -> `404`.
- **US13-S1** missing token -> `401`.
- **US13-S2** non-owner access -> `403`.
- **US13-O1** read metrics/logs/traces visible.

### 8) RestAssured Example
```java
RestAssured.given()
  .header("Authorization", "Bearer <user-token>")
  .get("/orders/{id}", "2f5d5485-9180-4e1f-9a4f-74f43dc8c718")
  .then().statusCode(200)
  .body("status", anyOf(equalTo("CONFIRMED"), equalTo("CANCELLED")));
```
