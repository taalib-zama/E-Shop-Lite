## FRD - User Story 21: Multi-Stage Docker Images and GHCR Registry

**ID:** US-21  
**Scope:** All service and platform modules  
**Primary flow:** `mvn package` -> Docker multi-stage build -> GHCR push  
**Status:** Ready for implementation

### 1) User Story
As a DevOps engineer, I want lean production images so all services can be reliably containerised and versioned.

### 2) Business Rules
- Multi-stage build: JDK-21 builder stage + JRE runtime stage.
- Image tag format: `ghcr.io/<org>/eshop-lite/<service>:<version>-<git-sha>`.
- Images must pass health probe check (`/actuator/health`).
- No secrets or credentials in image layers.
- Docker Compose `build:` contexts updated to use new Dockerfiles.

### 3) Functional Requirements
Multi-stage Dockerfile template:
```dockerfile
FROM eclipse-temurin:21-jdk AS builder
WORKDIR /app
COPY . .
RUN ./mvnw -pl services/<service> -am -q -DskipTests package

FROM eclipse-temurin:21-jre
WORKDIR /app
COPY --from=builder /app/services/<service>/target/*.jar app.jar
EXPOSE 808x
HEALTHCHECK --interval=30s --retries=3 CMD curl -f http://localhost:808x/actuator/health || exit 1
ENTRYPOINT ["java", "-jar", "app.jar"]
```

CI workflow (`ci.yml`) key steps:
```yaml
- name: Build and push image
  uses: docker/build-push-action@v5
  with:
    context: .
    file: services/<service>/Dockerfile
    push: true
    tags: ghcr.io/${{ github.repository_owner }}/eshop-lite/<service>:${{ env.VERSION }}-${{ github.sha }}
```

### 4) Data/Security/Observability/NFR
- No plaintext secrets in Dockerfile or CI env.
- Use GHCR `GITHUB_TOKEN` for registry auth.
- NFR: image size target `< 200MB` per service.
- Metrics: build duration tracked in CI summary.

### 5) Tech Lead Guidance
- Add one `Dockerfile` per module under `services/*/` and `platform/*/`.
- Parameterise port numbers per service.
- Update `docker-compose.yml` `build:` context entries.
- Add `.dockerignore` to exclude `target/`, `.git/`, local config files.

### 6) QA Matrix
- **US21-P1** image builds cleanly (`TC-S5-IMG-01`).
- **US21-P2** health probe returns `200` (`TC-S5-IMG-02`).
- **US21-P3** image tag includes Git SHA (`TC-S5-IMG-03`).
- **US21-N1** build fails on test failure.

### 7) CI Snippet
```yaml
name: CI
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-java@v4
        with: { java-version: '21', distribution: 'temurin' }
      - run: mvn -q verify
      - uses: docker/login-action@v3
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}
      - uses: docker/build-push-action@v5
        with:
          push: true
          tags: ghcr.io/${{ github.repository_owner }}/eshop-lite/user-service:latest
```
